# Shadowrocket 隱私與網路相容性設定指南

本指南說明如何在 Shadowrocket 中啟用 STUN 防護、改善部分 App 的網路相容性，以及使用 TUN 模式接管裝置流量。

---

## 一、啟用 STUN 防護

> 此設定可降低 WebRTC 透過 STUN 伺服器取得真實公開 IP 位址的風險。

1. 開啟 Shadowrocket。
2. 進入：

   ```text
   設定 → UDP
   ```

3. 開啟：

   ```text
   禁用 STUN
   ```

### 保護效果

- 阻止 WebRTC 使用 STUN 伺服器探索裝置的公開 IP 位址。
- 降低瀏覽器或 App 透過 WebRTC 洩漏真實 IP 位址的風險。
- 適合搭配瀏覽器的 WebRTC 防護設定一起使用。

> **注意：** 禁用 STUN 可能影響部分需要 UDP、P2P、語音或視訊通話功能的 App 與網站。若遇到通話、連線或媒體功能異常，可暫時關閉此選項進行測試。

---

## 二、啟用相容模式

> 相容模式是獨立的網路相容性選項，主要用於改善部分 App 對 Proxy 或 VPN 環境的連線問題；它不等同於 TUN 模式。

1. 開啟 Shadowrocket。
2. 進入：

   ```text
   設定 → 代理
   ```

3. 開啟：

   ```text
   相容模式
   ```

### 適用情況

若某些 App 在 Shadowrocket 啟用後出現以下情況，可嘗試開啟相容模式：

- 無法連線
- 無法載入內容
- 登入失敗
- 網路偵測異常
- 部分功能無法正常使用

> **注意：** 若目前所有 App 均運作正常，未必需要開啟相容模式。建議只在遇到相容性問題時啟用並測試。

---

## 三、啟用 TUN 模式

> Shadowrocket 的「代理型別：None」代表由 TUN 介面接管流量；概念上接近 Clash、v2rayN 或其他代理用戶端的 TUN 模式。

1. 開啟 Shadowrocket。
2. 進入：

   ```text
   設定 → 代理
   ```

3. 找到：

   ```text
   代理型別
   ```

4. 選擇：

   ```text
   None
   ```

### 運作方式

選擇 `None` 後，Shadowrocket 會使用 TUN 介面處理裝置的網路連線，而不是僅依賴傳統 HTTP 系統代理。

這通常有助於：

- 接管不支援 HTTP 系統代理的 App 流量。
- 改善部分 App、遊戲或服務的連線相容性。
- 讓 TCP 與可支援的 UDP 流量更容易納入代理規則處理。
- 降低部分流量繞過傳統系統代理的可能性。

> **重要：** TUN 模式不等於所有流量必然經代理伺服器。實際路由仍取決於你的 Shadowrocket 規則、設定檔、節點能力，以及 DNS 與 UDP 設定。

> **注意：** 部分 App 可偵測 iOS VPN／TUN 狀態，因此即使啟用 TUN 模式，仍可能拒絕執行或限制功能。

---

## 四、驗證設定效果

### 驗證 WebRTC IP 洩漏

1. 先連線至 Shadowrocket。
2. 開啟瀏覽器並前往：

   [BrowserLeaks WebRTC Test](https://browserleaks.com/webrtc)

3. 確認頁面未顯示：

   - 真實公開 IP 位址
   - ISP 原始 IP 位址
   - 未預期的 IPv6 位址
   - 區域網路／私人 IP 位址

### 驗證 App 相容性

開啟你常用的 App，測試以下功能：

- 登入與帳號驗證
- 網頁或影片載入
- 訊息與通知
- 語音／視訊通話
- 遊戲或即時連線服務
- 區域網路裝置存取

若啟用「禁用 STUN」後，通話或即時功能異常，可暫時關閉該選項再測試。

---

## 建議設定總覽

| 設定項目 | 建議值 | 作用 |
|---|---|---|
| `設定 → UDP → 禁用 STUN` | 開啟 | 降低 WebRTC 經由 STUN 洩漏真實 IP 的風險 |
| `設定 → 代理 → 相容模式` | 遇到 App 相容性問題時開啟 | 改善部分 App 在 Proxy／VPN 環境下的連線問題 |
| `設定 → 代理 → 代理型別` | `None` | 啟用 TUN 模式，由 TUN 介面接管網路流量 |
| Shadowrocket 規則／設定檔 | 依需求設定 | 決定流量要代理、直連或封鎖 |
| 瀏覽器 WebRTC 防護 | 建議另行啟用 | 提供瀏覽器層級的額外 IP 洩漏防護 |
